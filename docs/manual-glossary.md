# 用語集

製品の表示や本マニュアルに出てくる言葉の補足です（読み飛ばして構いません）。

- **フロー**：「どの帳票を・いつ・どこへ送るか」をまとめた配信の設定。
- **プラグイン**：送り先の種類ごとの部品（SQLite 用・S3 用 など）。
- **配信レポート**：送り先が「確かに入った」と返す確認データ（送信先・件数・ハッシュ）。これが取れて初めて成功扱い。
- **前回の更新時刻（差分の基準）**：差分配信が「ここ以降に更新された帳票だけ」を取り込むための基準時刻。前回成功した時点を覚えておき、次回はそこから再開します（取りこぼし防止・取得量の最小化）。
- **カタログ**：送信済みデータの索引（`~/.i-repo/catalog/`）。AI が最初に読む入口。
- **クエリ（読み返し）**：送信済みデータを安全に読み出すための仕組み（読み取り専用）。
- **MCP**：AI ツールにデータを読ませるための標準的な接続方式。
- **クラスター**：i-Reporter の帳票内で項目をまとめた単位。「詳細も一緒に送る」で取り込めます。
- **エージェンティック・プロジェクト**：既存フォルダを正本にして、Codex や Claude などのエージェントが作業する単位。アプリ内の登録はフォルダを削除しません。
- **プロジェクトフォルダ**：エージェンティック・プロジェクトの作業根となる既存フォルダ。データ namespace とは別のものです。
- **データの読み取り元（旧 Source binding）**：プロジェクトが参照する source の種類（なし／自分のテナント／共有／API）と識別子を結び付ける設定。
- **接続先 ID（旧 ownTenant の Source namespace）**：自分のテナントで接続先ごとに決まる識別子。トークンや秘密情報ではなく、通常は現在の接続先から自動入力します。
- **namespace**：共有または API の読み取り対象を識別する名前空間。1プロジェクトにつき、参照する識別子は0個または1個です。
- **context readiness**：プロジェクトが参照できる dataset の準備状況を示す表示。帳票の値ではなく、利用可能性を表します。
- **answerability（回答可能性）**：dataset の状態を表す指標。`queryable`（照会可能）、`degraded`（一部制限）、`semantic only`（意味情報のみ）、`unavailable`（利用不可）があります。
- **evidence（参照の根拠）**：チャットの回答で使った dataset、読み取り件数、読み取りの状態を示す情報。回答本文の自己申告ではありません。
- **completeness（完了性）**：読み取りがどこまで完了したかを表す指標。`complete`、`partial`、`semantic only`、`unknown` のいずれかです。
- **ephemeral chat（履歴は一時保持）**：プロジェクトチャットの会話を画面表示中だけ保持し、画面遷移やアプリ終了後に保存しない方式。
