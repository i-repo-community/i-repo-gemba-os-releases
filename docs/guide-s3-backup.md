# はじめての方へ：帳票を S3 に自動で保存しよう

i-Reporter の帳票を、Amazon S3（クラウドの保存場所）に毎日自動で保存する方法です。
**かかる時間は 10 分ほど**。画面に入力していくだけで、プログラムは要りません。

保存が終わると、S3 にはこんなふうに並びます。

```
2026-10-20/                              … 保存した日のフォルダ
├─ 27389_不具合報告シート.pdf             … 帳票の PDF
└─ 27389_不具合報告シート/                … 帳票ごとのフォルダ
   ├─ report.csv                         … 入力された値（Excel で開けます）
   ├─ report_27389_1_cluster_5.png       … 撮った写真
   └─ 27389_不具合報告シート.pdf
```

名前の先頭の数字は帳票の ID です。同じ名前の帳票があっても混ざりません。

## やることは 3 つだけ

1. **保存先を登録する** … 「どの S3 に置くか」をアプリに覚えさせます
2. **フローを作る** … 「どの帳票を、何と一緒に送るか」を決めます
3. **実行する** … ボタンを押して、うまくいったか確かめます

## 始める前に

次の 3 つがそろっているか確認してください。分からないものは、社内のシステム担当の方に聞いてください。

- **GEMBAOS データコネクト**（v0.50.0 以降）を入れて、i-Reporter につながっていること → [初回セットアップ](manual-setup.html)
- **AWS CLI** というツールがパソコンに入っていること（S3 へ送るときに使います）→ [AWS CLI のダウンロード](https://docs.aws.amazon.com/ja_jp/cli/latest/userguide/getting-started-install.html)
- S3 の **バケット名**・**リージョン**・**アクセスキー ID**・**シークレットアクセスキー** の 4 つ（システム担当の方からもらいます）

## 1. 保存先を登録する

左のメニューの **「接続先テンプレート」** を開いて、右上の **「＋ 配信先を追加」** を押します。

<figure class="screenshot">
  <img src="../assets/img/guide-s3/01-connections-add.png" alt="接続先テンプレート画面と「配信先を追加」ボタン">
</figure>

上の 3 つを選びます。

- **配信先名**: 自分で分かる名前（例「S3 データ保全」）
- **配信プラグイン**: `upload` を選ぶ
- **サブコマンド**: `push-s3` を選ぶ

<figure class="screenshot">
  <img src="../assets/img/guide-s3/02-connection-plugin.png" alt="配信先名・配信プラグイン upload・サブコマンド push-s3 を選んだところ">
</figure>

下に入力欄が増えるので、もらった情報を入れます。赤い枠のところだけで大丈夫です。

- **S3 destination**: `s3://` のあとにバケット名（例 `s3://my-company-gemba-backup`）
- **配置先サブパス**: `{date}` のままにします（日付ごとのフォルダに分かれます）
- **AWS アクセスキーID** と **AWS シークレットアクセスキー**: もらったキー
- **AWS リージョン**: もらったリージョン（例 `ap-northeast-1`）

  <img src="../assets/img/guide-s3/03-connection-s3.png" alt="S3 のバケット・配置先サブパス・アクセスキー・リージョンを入力したところ">
</figure>

右下の **「保存」** を押すと、一覧に出てきます。

<figure class="screenshot">
  <img src="../assets/img/guide-s3/04-connections-saved.png" alt="登録された配信先「S3 データ保全」の一覧">

## 2. フローを作る

左のメニューの **「フロー作成」** を開いて、右上の **「＋ フローを作成」** を押します。

<figure class="screenshot">
  <img src="../assets/img/guide-s3/05-flows-add.png" alt="フロー作成画面と「フローを作成」ボタン">
</figure>

**フロー名** を付けて、**対象期間** は **「差分」** を選びます。

「差分」にすると、前回のあとに増えた帳票や直された帳票だけを送ります。
パソコンを止めていた日の分も、次に動いたときにまとめて送ってくれます（1 回目は直近 30 日分）。

<figure class="screenshot">
  <img src="../assets/img/guide-s3/06-flow-basic.png" alt="フロー名と対象期間を入力したところ">
</figure>

**「抽出オプション（詳細パラメータ）」** を押して開き、次の 3 つのスイッチをオンにします。

- **帳票CSV一式を含める**
- **クラスター画像・録音を含める**（写真や録音も入れる）
- **PDFを含める**

「出力形式」は `pdf` のままにします。

<figure class="screenshot">
  <img src="../assets/img/guide-s3/07-flow-csv.png" alt="出力形式 pdf と、帳票CSV一式・画像・PDF のスイッチをオンにしたところ">
</figure>

下のほうの **「＋ 配信先を追加」** を押して、さっき登録した **「S3 データ保全」** を選びます。

<figure class="screenshot">
  <img src="../assets/img/guide-s3/08-flow-dest.png" alt="配信先に S3 データ保全を選び、経路のプレビューが i-Reporter → 抽出 → S3 データ保全 になったところ">
  <figcaption>「i-Reporter → 抽出 → S3 データ保全」とつながっていれば OK です</figcaption>
</figure>

右下の **「保存」** を押します。

フローの一覧で **「▶ 即時実行」** を押します。

## 毎日自動で保存するには

1. フローの **「編集」** を押し、**「実行条件」** で「毎日」と時刻を選んで保存します
2. 同じ画面の **「着信 Webhook」** をオンにして保存します
3. 左のメニューの **「スケジュール」** で、このフローの **「登録」** を押します

アプリを起動しておけば（最小化していても大丈夫です）、決まった時刻に保存してくれます。
くわしくは [スケジュールの画面](screen-scheduler.html) を見てください。

## 困ったときは

**「成功」にならない**
左のメニューの **「ログ（i-repo）」** に理由が出ます。よくあるのは次の 4 つです。
AWS CLI が入っていない／キーの入れ間違い／リージョンの入れ間違い／そのバケットに書き込む許可がない。

**同じ日に 2 回実行したら？**
同じ日付フォルダの中で、新しい内容に置き換わります。ファイルが二重に増えることはありません。

**写真が入っていない帳票がある**
写真や録音が入力されている帳票だけ、フォルダに画像が入ります。

**日付フォルダに分けたくない**
1 の「配置先サブパス」を空にすると、バケットの一番上にそのまま並びます。

**PDF はフォルダの中だけでいい**
2 の「出力形式」を `none` にすると、フォルダだけになります。

## システム担当の方へ

- アクセスキーには、対象バケットへの `s3:PutObject`（書き込み）と `s3:ListBucket`（書き込んだあとの確認）の権限があれば足ります
- シークレットアクセスキーは画面上で伏せ字になり、送るときに AWS CLI へ渡すだけです。キーの代わりに環境変数の名前を登録することもできます（「環境変数から読む」）
- `report.csv` は i-Reporter が出力したままの文字コード（Shift_JIS / CP932）です。Excel 以外で読むときは文字コードを指定してください
- 「成功」は、S3 に置いたあとにファイルの有無と大きさを照合した結果です
- 同じ名前のファイルは上書きで置き換えます。バケットのバージョニングが有効なら、前の版も S3 に残ります
- 「接続テスト」が確かめるのは AWS CLI の有無だけです。キーやバケットにつながるかまでは確かめません
