# ログ（i-repo）

送信の裏側で何が起きたかの**詳しい記録**を、**読み取り専用**で見る画面です。
うまくいかないときの原因調べに使います。

- ふだんの成否の確認は **[実行状況](screen-runs.html)** で足ります。この画面は、
  そこだけでは原因が分からないときに開いてください。
- 直近 7 日分の記録を、**日付を選んで**表示します。パスワードなどは伏せ字で記録されます。
- 種別（コマンド・通信・完了・エラー）や **「失敗」** で絞り込み、キーワード検索と併用できます。
- **「自動追従」** を入れると、今動いている処理の記録が数秒ごとに追いかけ表示されます。
- **「フォルダで開く」** で、記録ファイルの場所をそのまま開けます。
  記録が大きいときは末尾だけを表示し、その旨をお知らせします。
