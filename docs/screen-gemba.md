# 現場蓄積データ

送信が終わったデータを、アプリ内で**読み取り専用**で閲覧・検索する画面です。AI が読むのと同じ仕組みを、人間が画面で見られるようにしたものです。

- データセットを選ぶと一覧が表示されます。
- **詳細** ボタンで、項目（クラスター）の値・添付ファイル・元データを確認できます。
- 配信フローの **[実行状況](screen-runs.html)**（実行ログ・成功確認・再実行）もこの画面から開けます。
- 送り先のパスやパスワードなどの接続情報は表示しません（安全のため）。

### 帳票の PDF をその場で開く

レコードの **詳細** を開くと、いちばん上に**その帳票のファイル（PDF・画像など）**が並びます。

- **🌐 開く** — ブラウザで表示します。クラウドへ配信したものは有効期限つきの一時 URL で開くので、
  この端末にコピーを残しません。ローカルに置いたものは、その配信の実行状況が開きます。
- **⬇ 保存** — 手元に保存します（ローカルにあればコピー、無ければクラウドから直接取得）。
- 開くときは、その帳票（と改版）に対応する配信を新しい順にたどって実体を探します。
  **同じ帳票のものだと確認できない場合は開かず**、その配信の実行状況へ案内します。

### その場で「付箋」（意味づけ）

レコードの詳細を開くと、クラスター値の表の各行に **「付箋」ボタン** が出ることがあります
（帳票定義に紐づくフローで、詳細つきで配信されているデータセットの場合）。
実データを見て意味が分かった、その場で項目の意味・正準名・型を付けて確定できます
（Ontology Studio と同じ編集画面が開きます）。
